# Plantilla de módulo

Duplica esta carpeta y cámbiale el nombre cuando crees una funcionalidad nueva.

```text
mi-modulo/
  actions.ts     Entrada: formulario, petición o Server Action.
  service.ts     Reglas de negocio.
  repository.ts  Lectura y escritura de datos.
  types.ts       Tipos compartidos del módulo.
```

Los archivos están vacíos a propósito.
